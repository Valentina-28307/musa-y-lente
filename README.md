# Musa y Lente — Portafolio

Sitio web de portafolio para la marca de fotografía **Musa y Lente**, especializada en fotografía de producto y retrato.

## 🔗 Sitio desplegado

👉 [https://musa-y-lente.vercel.app](https://musa-y-lente.vercel.app)

## 🛠️ Tecnologías utilizadas

- HTML5 semántico
- SCSS con arquitectura de partials (variables, nesting, mixins, `@extend`)
- Bootstrap 5 (navbar, carousel, cards y grillas)
- AOS (animaciones al hacer scroll) y animaciones nativas con `@keyframes` y `transition`
- Diseño responsive para mobile, tablet y desktop
- SEO on-page: títulos y meta tags únicos por página, `alt` descriptivos y jerarquía de encabezados

## 📄 Páginas del proyecto

- `index.html` — Inicio
- `pages/sobre-mi.html` — Sobre mí
- `pages/proyectos.html` — Proyectos
- `pages/servicios.html` — Servicios
- `pages/contacto.html` — Contacto

## 📁 Estructura de carpetas

- `scss/` — estilos fuente en SCSS (`main.scss` solo importa los partials)
- `styles/` — CSS compilado
- `assets/` — imágenes y recursos multimedia
- `pages/` — páginas internas del sitio
